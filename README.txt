PokDex v2.30 — Mode hors connexion

Contenu : index.html, service worker, manifeste PWA et icônes.

Installation : téléverse TOUS les fichiers et les deux icônes à la racine du dépôt GitHub Pages (pas seulement index.html). Publie le site en HTTPS.

Premier téléchargement hors connexion : ouvre le site publié avec Internet, va sur Accueil et appuie sur « Télécharger les données et images ». Garde la page ouverte, de préférence en Wi-Fi. Le téléchargement peut être volumineux et prendre du temps. Les ressources déjà mises en cache sont conservées si le téléchargement est interrompu.

Ensuite, teste le site en mode avion. Le cache dépend du navigateur et de l'appareil ; ne vide pas les données du site si tu veux conserver le contenu hors connexion.

Limites : les images des cartes déjà intégrées restent disponibles. Les ressources récupérées de PokéAPI et des dépôts GitHub sont mises en cache après téléchargement. Le navigateur peut limiter le stockage ou certains téléchargements ; le statut indique les échecs.
